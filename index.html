ระบบรดน้ำต้นไม้อัจฉริยะ

ตรวจวัดความชื้นในดิน เทียบกับเกณฑ์ตามชนิดต้นไม้ แล้วแจ้งเตือนเมื่อควรปิดวาล์วน้ำ

เบราว์เซอร์นี้ไม่รองรับ Web Serial API ใช้งานได้เฉพาะโหมดจำลอง

เลือกชนิดต้นไม้

เกณฑ์ปัจจุบัน
เริ่มรดน้ำ: ต่ำกว่า 35%
หยุดรดน้ำ: ถึง 60%
ปั๊ม/วาล์วน้ำ: ปิดอยู่ โหมดสั่งเอง

ความชื้นอยู่ระหว่างการรดน้ำ • โหมดจำลอง

ประวัติเหตุการณ์

ยังไม่มีเหตุการณ์ — ลองลากแถบจำลองความชื้นดู

หมายเหตุ: ค่าเกณฑ์ความชื้นเป็นตัวอย่างสำหรับทำโครงงาน ไม่ใช่ค่ามาตรฐานสากล ควรปรับตามชนิดดินและผลทดลองจริง การเชื่อมต่อ Arduino ใช้ Web Serial API ผ่านสาย USB (รองรับเฉพาะ Chrome/Edge บนคอมพิวเตอร์)
